Modifications made for this site:
- React components rewritten as Django templates and vanilla JavaScript.
- CSS files concatenated into css/resume.css; the Google Fonts import removed
  and Inter / Space Mono self-hosted (css/fonts.css).
- Content, contact details and projects replaced with Mahdi Shafiei's own;
  projects and messages come from the Django database and admin.
- The contact form stores messages in the site's database instead of calling
  the Resend email API; the WhatsApp link was removed.
- Timeline visualizers redrawn for Mahdi's stages in the same canvas style.
- The Three.js black-hole shaders (GLSL) render the same image, restructured
  for speed: the ray trace, which depends only on the camera, is cached per
  pixel and redone only when the camera moves, while each frame shades the
  animated disk noise and drifting stars on top of it; noise and star terms
  that are multiplied to zero are skipped. Every device traces the full 200
  steps (upstream used 120 on low-power devices, which lost the lensed ring).
  The hero headline scales with the window height on short screens so the
  whole hero fits.
- Cursor hover styles are set as classes from JavaScript instead of
  body:has(...:hover) selectors; pull-to-refresh is disabled on the page root.
